# Sklews

Премиум-мессенджер с каналами, чатами, друзьями и валютой ✦ Кристаллы.

## Возможности

- Регистрация / вход
- Каналы (создание, подписка, посты, лайки)
- Личные чаты в реальном времени
- Система друзей (заявки, принятие)
- Валюта ✦ (начисление за активность)
- Супер-сообщения
- Бусты каналов
- Фильтры ленты

## Запуск в Termux

```bash
cd ~/Sklews
pip install -r requirements.txt
python app.py
```

Открыть: http://127.0.0.1:5000
