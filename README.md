# Sklews

Премиум-мессенджер с каналами, чатами, друзьями, ролями, магазином и валютой ✦.

## Что реализовано

- Регистрация / вход
- Каналы + посты + лайки + закрепление
- Подписки + непрочитанные + уведомления (долгое нажатие)
- Роли: владелец / админ / модератор / соавтор
- Личные чаты + супер-сообщения (30 ✦)
- Друзья (заявки, принятие, список)
- Валюта ✦ + ежедневный бонус (нажми на кристаллы)
- Бусты каналов (бронза/серебро/золото)
- Премиум-статус
- Темы каналов
- Базовая аналитика
- Фильтры ленты
- Редактирование статуса (нажми на статус)

## Запуск

```bash
pip install -r requirements.txt
python app.py
```
